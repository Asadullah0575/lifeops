# LifeOps

Autonomous personal operations agent built for the Agents for Humans Hackathon (Aug 22 - Sep 14, 2026).

LifeOps detects responsibilities from documents and events, extracts what matters, takes safe actions,
verifies the results, remembers useful context, and asks for human approval when a decision matters.

## Core loop
Detect -> Understand -> Decide -> Act -> Verify -> Remember -> Escalate when necessary

## Stack
Next.js + TypeScript, Strands Agents SDK, Amazon Bedrock, AgentCore Runtime + Memory, DynamoDB, S3, CloudWatch.
